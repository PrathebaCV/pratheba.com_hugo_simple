# AWS Services Overview - Part 1

This document provides a comprehensive overview of key AWS services for monitoring, logging, and application performance management.

## CloudWatch Services

### Alarms: 
Alerts based on specific metric thresholds, such as high CPU utilization on an EC2 instance.
### Logs: 
Collect, monitor, and analyze log data from different AWS services and applications.
### Log Anomalies: 
Detect unusual patterns in log data automatically using machine learning.
### Live Tail: 
Real-time monitoring of logs to instantly see application issues.
### Log Insights: 
Query and analyze logs for troubleshooting application issues and system performance.
### Metrics:
 Monitor and track performance data from AWS resources like EC2, RDS, etc.
### X-Ray Traces: 
Analyze distributed application traces to identify performance bottlenecks and latencies.
### X-Ray Trace Map: 
Visualize service maps for end-to-end tracing of distributed applications.
### Events: 
Automate responses to changes in your AWS environment by setting up event-driven actions.
### Contributor Insights: 
Analyze high-cardinality datasets to identify top contributors to system performance issues.

# Part 2

### Service Map: 
Visual representation of relationships between AWS services in your architecture.
### Service Level Objectives (SLOs): 
Define and measure service level objectives to monitor compliance with business requirements.
### Synthetics Canaries: 
Simulate user interactions with an application to monitor availability and performance.
### RUM (Real User Monitoring): 
Monitor and collect data from real user interactions in your application to detect issues.
### Evidently: 
Experiment with new features in your application and monitor their performance with controlled rollouts.
### Internet Monitor: 
Monitor internet-facing applications for global performance and availability issues.
### Network Monitor: T
rack and monitor network performance, identify traffic bottlenecks, and detect network issues.
### Container Insights: 
Gain insights into containerized applications and their performance in real-time.
### Lambda Insights: 
Collect detailed metrics and logs for AWS Lambda functions to monitor their performance.
### Application Insights:
 Detect issues with application workloads running on AWS resources automatically.
### EC2 Resource Health: 
Monitor the health of Amazon EC2 instances and receive alerts if there are potential issues.
